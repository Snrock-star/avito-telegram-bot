AVITO RADAR TELEGRAM BOT — развертывание на Render

1) Создай GitHub-репозиторий и загрузи в него main.py, requirements.txt, render.yaml.
2) Render.com → New → Blueprint → подключи репозиторий.
3) В настройках сервиса добавь Environment Variable:
   BOT_TOKEN = токен от @BotFather
4) Нажми Deploy.
5) В Telegram открой своего бота и отправь /start.
6) Отправь полную ссылку на поиск Авито. Все параметры и фильтры в URL сохраняются.

Команды:
/start — приветствие
/help — помощь
/add — подсказка добавить поиск (также можно просто отправить URL)
/list — активные поиски
/pause — пауза по всем поискам
/resume — возобновить
/delete — удалить поиск (далее отправь номер из /list или «все»)

ВНИМАНИЕ:
- На бесплатном тарифе Render worker может быть недоступен/ограничен; проверь актуальные условия тарифа перед публикацией.
- Для сохранения базы нужен постоянный диск. Render может не включать persistent disk в бесплатный тариф. Если диска нет, база может сбрасываться после перезапуска/деплоя.
- Авито может возвращать CAPTCHA, 403/429/401 или менять HTML. Этот код не обходит CAPTCHA, ограничения или авторизацию. При таких ответах бот уведомит тебя и попробует позже.
- Проверка новых карточек выполняется по ссылкам объявлений в выдаче. Для точного извлечения всех деталей карточки дополнительно открывается сама карточка; часть полей может быть недоступна без входа.
- Не публикуй BOT_TOKEN. Если токен утёк — отзови его у @BotFather и создай новый.
